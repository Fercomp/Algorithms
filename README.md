# Algorithm Repository

This repository contains a collection of algorithm problems that I’ve solved over time.

It's all in Python, as it’s my second strongest language and makes it easier to focus on problem-solving compared to Swift.

The codebase is not fully standardized yet. The problems were gathered from different platforms and solved over a long period of time, so you may find inconsistencies in style, structure, and even language (some files are in Portuguese, others in English).

I also tend to leave comments for my future self, but they are not always polished or useful for others.

## Naming Conventions

* **LC** → LeetCode problem
* **CCI** → Cracking the Coding Interview
* **UVa** → UVa Online Judge
* **HR** → HackerRank

Not every file corresponds to a specific problem — some are just experiments to better understand certain concepts.
